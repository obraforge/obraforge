# Página: `/skills`

**Objetivo:** achar a skill certa. **Conversão:** clique numa skill.

**SEO:** title `Skills — obraforge`; meta description `Todas as Agent Skills do obraforge, por
área e fase. Busque por orçamento, edital, PGR ou outro assunto de obra.` JSON-LD:
`BreadcrumbList`.

## Seções

1. H1: `Skills`. Linha: `{n} skills na versão {versão} do catálogo.`
2. **Busca e filtros** (só com JavaScript; sem ele, a lista inteira aparece): campo `Buscar por
   assunto, como edital ou orçamento`; filtro de área (as áreas com skill); filtro de fase.
   Estado vazio: `Nenhuma skill com esses filtros.`
3. **Lista:** um item por skill, gerado do catálogo: nome, área, fase, versão, estado (marca
   `depreciada` quando for o caso) e a descrição.
