# Página: `/areas/<tag>`

**Objetivo:** mostrar o que existe numa área. **Conversão:** clique numa skill. Só existe página
para área com skill publicada.

**SEO:** title `{área} — obraforge`; meta description `Agent Skills do obraforge na área {área}.`
JSON-LD: `BreadcrumbList`.

## Seções

1. H1: o nome da área. Linha: `{n} skill(s) nesta área.`
2. A mesma lista de `/skills`, filtrada pela área.
3. Link: `Ver todas as skills` → `/skills`.
